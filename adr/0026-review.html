Three pillars

A · Compact tools

Collapsed header: tool name + one-line preview. Expand reveals full body. Optional expand-all. Attachments/screenshots stay visible when collapsed (rec).

B · Timestamps

From existing created_at. Same day → time only; else short date+time. Full ISO in tooltip. No backend change for v1.

C · Thinking status

Single ephemeral line driven by turn / status SSE (calling model, running tool name…). Not written into session MD. Gone when turn goes idle.

Tool density

Q1 Default tool density?
Rec: collapsed one-line; click to expand.
Q2 Group all tools since last user message into one “N tools” accordion?
Rec: no in v1 — per-tool compact rows.
Q3 Expand-all control placement?
Rec: transcript toolbar near session actions.
Q4 Persist “tools expanded by default”?
Rec: localStorage first.

Timestamps

Q5 Timestamp display format?
Rec: time-only same day; else date+time; ISO tooltip.
Q6 Show timestamps on tool rows too?
Rec: yes, subtle on compact header.

Thinking / status

Q7 Thinking status: in-transcript line vs only turn card?
Rec: both — live one-liner + existing turn card.
Q8 Persist thinking lines after the turn ends?
Rec: no — ephemeral only.
Q9 Demote harness advisories into the status strip?
Rec: keep harness bubbles; ephemeral line is phase/tool only.
Q10 Screenshots on collapsed tool rows?
Rec: always show image chips when collapsed.
