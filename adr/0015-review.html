2. Fire path (locked)

ticker → due jobs (enabled, next_run_at ≤ now)
       → advance next_run_at (no catch-up)
       → if limp / model down → skipped_limp
       → if session busy → skipped_busy
       → if session missing → create session, rebind job.session_id
       → inject "[cron:id name]\n" + prompt → start turn
       → write cron_runs (ok | created_session | skipped_*)
