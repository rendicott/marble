Native web_fetch tool

After web search returns real URLs (Tavily search already does), fetch page text in-harness instead of defaulting to Tavily extract/crawl/research for every hit.

Date2026-07-18

1. Preferred pipeline

mcp_tavily_tavily_search  →  [{title, URL, snippet}, …]
         ↓ model picks real https URLs
web_fetch(url)            →  extracted text/markdown (capped)
         ↓
cite + answer

Tavily extract/crawl/research only if fetch fails or multi-page crawl needed
Search discovers; web_fetch retrieves. Do not invent URLs.

2. Tool sketch

web_fetch({
  url: "https://…",          // required, http(s) only
  max_bytes?: number,
  extract?: "text" | "markdown" | "raw_html_snippet"
})

→ url / final_url / status / content_type / chars
---
extracted body (truncated to max_tool_result)
  • Turn-context cancel (ADR-0010)
  • SSRF: block localhost/private/metadata by default
  • Prefer over shell curl for model-driven reads
