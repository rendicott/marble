Mutual handshake

1. Marble Settings → Pair  →  H-XXXXXX  (+ harness URL)
2. Peer CLI or http://127.0.0.1:…/pair  →  enter H-code
3. Peer shows P-XXXXXX
4. Operator enters P-code in Marble
5. Seal device credential; prefer HTTPS (HTTP private OK w/ confirm)
6. Peer dials WS (default)
