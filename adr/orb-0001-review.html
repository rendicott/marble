Open questions

Already locked (from this thread)

Q0a Brand / domain?
Rec: Canonical domain orbnet.app (apex portal, www→apex, api.orbnet.app, gw.orbnet.app).
Q0b Envelope vs body?
Rec: Fan-out ≤2KB envelope; body stored once, fetch on open, cap 1MB UTF-8. No extra fetch tiers. Bots opt in to bodies. Meter envelopes + fetch GB.

Product / positioning

Q1 Who is the first user?
Rec: You + Marble only for the spike (API-first). Homelab/public after the loop works.
Q2 Hosted SaaS, self-host binary, or both from day one?
Rec: Hosted only in v1. Self-host later (ntfy’s growth path, not ours yet).
Q3 Compete with ntfy or integrate?
Rec: Don’t clone ntfy. Optional BYO ntfy topic as wakeup. Compatibility POST later.
Q4 Public topics: world can listen only, or unauthenticated publish like ntfy?
Rec: Listen-only. Keyed publish only.
Q5 Are paid topics (subscribers pay publishers) in v1?
Rec: No marketplace in v1. Publisher usage billing only, or free until it hurts.
Q6 Tone of clients?
Rec: Ops terminal / control room. Dense markdown. Not Slack, not Pushover-cute.

Message model

Q7 Attachments in v1? Inline images?
Rec: No attachments. No HTML. Images as https links only; server does not fetch them.
Q8 Binary / JSON-only agent payloads vs markdown-only?
Rec: Markdown is the product. Optional agent front matter. JSON stored as blob if posted, not a second UX.
Q9 Priority: ntfy 1–5 or silent/normal/urgent?
Rec: Keep 1–5 on the envelope (steal ntfy).
Q10 Retention defaults?
Rec: 7d private bodies, 24h public bodies; envelope index 7d. Weekend-offline agents need more than 12h.
Q11 Replay for humans vs bots — same topic?
Rec: Same topic. Envelope firehose for both; bots opt into bodies + durable cursor.
Q12 Threading / run_id grouping in UI?
Rec: Flat per-topic feed in v1. Client may cluster by run_id. No Slack threads.
Q13 Read receipts / delivery acks to publishers?
Rec: No in v1. Fetch logs are ops/metering only.
Q14 Who writes the envelope preview?
Rec: Server-truncated from title + start of body. Publisher cannot stuff the envelope.

Auth & keys

Q15 Verified email required, or GitHub OIDC enough?
Rec: Email verify to create topics. OIDC optional extra.
Q16 One key many topics, or topic-scoped only?
Rec: Publish keys topic-scoped. Account admin key is not a publish key by default.
Q17 Subscriber API keys on public topics?
Rec: Not required. Optional for bots (rate/cursor).
Q18 Invite link: one topic or org bundle?
Rec: Single-topic invites in v1.
Q19 Stolen invite — unlimited devices?
Rec: Default max 10 uses, 7d expiry, 5 devices/grant, revocable.
Q20 Anonymous → billed account merge across devices?
Rec: Device key signs merge; union subscriptions; account prefs win.

Clients & platforms

Q21 Client stack?
Rec: Web + Tauri desktop first. Phone via ntfy bridge until store apps. Flutter later.
Q22 Linux tray — which desktops?
Rec: SNI/AppIndicator. GNOME may hide tray; OS notifications still required.
Q23 macOS menu bar vs dock?
Rec: Menu bar extra; dock optional; bounce only priority ≥4.
Q24 Signed/notarized installers in MVP?
Rec: Raw binaries for spike. Notarize when accounts exist.
Q25 Who owns Apple/Google developer accounts?
Rec: Your personal accounts until a legal entity. Desktop doesn’t wait on stores.
Q26 UnifiedPush / ntfy-as-distributor on Android?
Rec: Skip in v1.
Q27 Web portal as billing system of record for CLI-only users?
Rec: Yes.

Notification policy

Q28 If Mac is unlocked, suppress phone?
Rec: No in v1. Per-device prefs only.
Q29 Global DND vs per-topic mute vs publisher priority — who wins?
Rec: Subscriber sovereign. DND > mute > priority-as-loudness.
Q30 Can publishers mark un-muteable urgent?
Rec: No. Subscriber always sovereign.
Q31 Digest algorithm?
Rec: Hourly/daily envelope rollup. Off by default.
Q32 Install ntfy for v0 phone push — BYO topic or Orb-hosted relay?
Rec: BYO ntfy topic in subscriber prefs. No Orb-hosted ntfy.
Q33 Postcard / lock-screen contents?
Rec: Title only by default on private topics. Optional short preview.

Architecture / infra

Q34 NATS on ECS vs Synadia Cloud vs skip broker?
Rec: Spike without NATS if possible; JetStream on ECS when fanout hurts. No Synadia yet.
Q35 Single region which city?
Rec: us-west-2, single region.
Q36 Isolate JetStream per tenant now?
Rec: Shared stream, subject per topic. Isolate later.
Q37 Max subscribers per topic in v1?
Rec: Design for 10k. Don’t market millions.
Q38 VPC / PrivateLink for enterprise agents?
Rec: No in v1.
Q39 IaC: Terraform or CDK? Existing AWS org?
Rec: Terraform, dedicated orb-prod account.
Q40 Observability vendor?
Rec: CloudWatch + OTel. Grafana Cloud optional.

Billing & legal

Q41 Who is the legal entity charging cards?
Rec: Nobody yet. Free until entity + Stripe.
Q42 Free cap numbers?
Rec: 3 public + 1 private; 10k envelopes; 2GB fetch; 1GB stored.
Q43 Price points?
Rec: Defer. No public pricing in spike.
Q44 Data residency / EU region?
Rec: US only in v1. Disclose it.
Q45 E2E encrypt agent traces?
Rec: No in v1. Server sees plaintext.
Q46 Content moderation / CSAM if public markdown?
Rec: No uploads in v1. ToS + report + freeze. Revisit if attachments land.

Agent-specific

Q47 First-class MCP server for Orb?
Rec: Yes after HTTP API. Not in the first spike weekend.
Q48 Bidirectional replies / agent.ask Accept-Deny?
Rec: One-way in v1. Ask-actions in v2 with signed callbacks.
Q49 Schema registry or freeform markdown forever?
Rec: Encourage front matter. Don’t enforce a registry yet.
Q50 Agent feedback loops across topics?
Rec: Hop header, max 8, drop cycles.
Q51 Replace email/Telegram in Marble, or sit beside them?
Rec: Beside them. Another sink, not a replacement yet.
Q52 ntfy-compatible publish URL on api.orbnet.app?
Rec: After native API, yes as a gateway. Not spike-critical.

Ops / team

Q53 Who runs on-call?
Rec: You. Best-effort. No fake SLA.
Q54 Budget ceiling first 90 days?
Rec: Low hundreds USD. Don’t buy store listings yet.
Q55 Open source clients / server / neither?
Rec: Closed for now. Revisit when the product exists.
Q56 Success for a 6-week spike?
Rec: Marble → private topic → Mac tray envelope → fetch body. Phone via ntfy optional.
