Effective model resolve

per turn:
  1. CronModelID in TurnOpts   (this fire only — does not rewrite session)
  2. session.model_id          (if set + enabled in catalog)
  3. process CLI fallback      (--model / --base-url / limits / --api-key-env)

dual fields:
  model_id  = catalog slug (or "")
  model     = last effective provider model string
  API also exposes model_effective { limits, caps, source }

Context shrink

PATCH does not rewrite history. Next turn trimHistory uses active budget. Auto-compact cascade after shrink is intentional. In-turn compact uses the turn’s already-resolved em (including cron pin); source trimmed to 80% of em.Budget().
