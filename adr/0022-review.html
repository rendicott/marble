Design sketch (defaults)

TurnContext + Fingerprints ring + BanList + EscalateLock + Checklist

Execute(tool):
  F = fingerprint(name, normalize(args))
  if F in BanList → error
  if count(F) ≥ N → hard error "anti-repeat… NEXT: different class | confirm | API"
  else run; append event

Stuck (anti-repeat on computer_* | K computer failures):
  EscalateLock → advisory every model call
  optional: reject same-class clicks until confirm / new class

autoStopAndContinue:
  prompt += checklist, last URL, last tools, ban list, rules

shell pure sleep → reject → use browser wait
eval mutate ≥ M → hard error → click_text/type/set_input_files
peer open → dismiss Restore/Not now once
