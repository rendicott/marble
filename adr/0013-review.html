2. Composition (each model call)

1. [system]  immutable defaultSystemPrompt
2. [system]  soul.md contents   (omit if empty)
3. … conversation / tools …
4. [system]  ephemeral advisories (existing loop)
Soul is not written into session Markdown as chat turns. Changing soul affects future model calls only.
