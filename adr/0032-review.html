Design (proposed)

A · Cookie

Name marble_theme, value dark|light|tan, Path=/; Max-Age=31536000; SameSite=Lax, Secure only on https. Not HttpOnly. Unknown → dark.

B · Boot

Inline <script> in index.html <head> before style.css. Sets html[data-theme] and color-scheme. No network, no settings.js.

C · Tokens

html[data-theme="…"] { --bg: … }. Retokenize hardcoded chrome hex in style.css. Status colors stay recognizable (green / amber / red) across themes.

D · Out of scope

ADR pages, mpub, Wonderstand, desktop peer, prefers-color-scheme auto, SQLite, custom palettes, per-session theme.

PRScope
T1Boot script + data-theme=dark identical to today + cookie helpers
T2Retokenize style.css hardcoded hex
