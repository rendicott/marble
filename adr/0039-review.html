Harness state portability

rinux lost its Wi-Fi adapter and was dark for days. Every fact this harness knows — transcripts, knowledge, skills, model catalog, cron, peer pairings, secrets — lives on one disk on one box with no backup job and a 90%-full root filesystem. The next dead dongle should cost an afternoon, not a week.

Goal

  • marble-harness state export|import moves a memory leaf between machines, with a manifest and checksums.
  • Secrets do not travel in the clear: $MEMORY/env is omitted by default, encrypted with age on request.
  • A warm standby pulls snapshots in the background and stays read-only until promoted.
  • Promotion is a written runbook with a lease, not a guess about which box is primary.

Locked

L1 Export/import ships first.
Rec: state export [-out PATH] [--stats] [--secrets=omit|age], state import [-in PATH] [-apply] [--rewrite-workspace FROM=TO].
L2 Secrets are opt-in and encrypted.
Rec: manifest records "secrets":"omitted" plus the key names present, never values.
L3 Snapshot, do not copy files.
Rec: copying marble.db + -wal from a live process is corrupt-on-arrival.
L4 Pull, don't push.
Rec: lag target ≤ 2 min; state export --flush persists dirty sessions before a planned cut.
L5 Fencing is a lease, not a file lock.
Rec: --force is the loud path for declaring the old box dead.
L6 No home-directory imaging.
Rec: the operator's workspace is not harness state; a separate backup job owns it.

Open questions

Q1 Snapshot endpoint on the live harness, or stop-the-world export only?
Rec: POST /api/admin/state-snapshot; keep stop-the-world as the fallback.
Q2 Where does the standby live?
Rec: not spark-37a9-280 (couples no-model with no-memory), not rinis-mac-mini (a different operator leaf).
Q3 Hostname steal or URL rewrite?
Rec: steal on emergency, rewrite on planned. Check Google OAuth redirect URLs either way.
Q4 Where does the age identity live?
Rec: never on the box being backed up; losing it means re-minting every key by hand.
Q5 Are the pre-image backups in the bundle?
Rec: yes by default; measure first. Note the root filesystem has ~11 G free.
Q6 Do we rewrite absolute paths in transcripts?
Rec: report only. Prose false positives outweigh the benefit.
Q7 Order of work?
Rec: Phase 1 (days) → nightly timer (hours) → Phase 2 standby (about a week) → Phase 3 promote (days).
