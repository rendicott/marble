3. Limp mode

⚠ Limp mode: database schema incompatible — writes disabled. Chat, tools, and Markdown sessions still work.

On

  • Chat (CLI model)
  • Workspace tools
  • New sessions → Markdown
  • List from session/*.md
  • MD flush daemon

Off

  • All DB writes
  • DB dual-write events
  • If DB newer than binary: ignore DB entirely

Lock conflict → exit, not limp.

6. Optional remaining questions

Won’t block if you accept defaults.

O1 · Blob id scheme
Default: UUID v4 filename; optional sha256 column for later dedup.
O2 · Limp banner severity
Default: warning (amber), non-blocking.
O3 · Health JSON field names
Default: mode, schema_version_db, schema_version_binary, limp_reason.
O4 · Auto-close stale active sessions?
Default: no — only explicit close.
O5 · Two harnesses, different --memory paths?
Default: allowed (lock is per directory).
