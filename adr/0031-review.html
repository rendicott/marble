Subprocess context injection — pick-and-choose session context

call_agent_process and routed turns spawn the child cold — only the prompt crosses. This ADR adds an explicit context control: a list of named sources (transcript, memory, files-read) assembled into one size-capped block and injected into the child. Default off. Chosen per call, per session, or as a preset/global default.

Context sources (composable)

context is a list, not an enum, so sources compose:

context: ["full", "memory"]        # transcript + older digest + top memory matches
context: ["read_paths"]             # files touched this turn
context: "none"                     # [] — today's behavior (default)
context: "auto"                     # read_paths + compact; upgrade if prompt references prior work
tokencontributiondefault cap
compactsession_compact digest6000 chars
fullrecent raw turns (capped) + compact of older12000 + 6000
memorytop-K memory_search hits seeded from prompt + recent turns4000
read_pathspaths read/written this turn1500
full implies compact (its "older" section is a compact); both together = no double-count.

Assembly & delivery

[CONTEXT — Marble session 0wdvhcj0q0 · source: full]
…recent transcript…

[CONTEXT — Marble session 0wdvhcj0q0 · source: memory]
…top matches…

[CONTEXT — Marble session 0wdvhcj0q0 · source: read_paths]
…
  • Per-source caps, then a total cap (context_max_chars, default 16000).
  • Overflow: truncate oldest-first (transcript) / lowest-relevance-first (memory), then drop lowest-priority source (read_paths → memory → full → compact).
  • Assemble(session, spec) is a pure function — deterministic, testable.
  • Delivered as a prepended section to the prompt (driver-agnostic), not --resume/CLAUDE.md.
  • Never echoed in prompt_preview/command — only a size marker (context: full+memory · 14k chars).

Config surface

// session override (new tool)
session_set_subprocess_context { "context": ["full","memory"], "max_chars": 24000 }
// → echoes effective config; [] or "clear" reverts to default

// preset default (Settings → Agents → preset editor, schema v9)
{ "id": "claude-full", "driver": "claude", "context": ["read_paths"], "context_max_chars": 16000, … }

// global default (agent_process.json)
"context": { "default": ["read_paths"], "memory_top_k": 5, "max_chars": 16000, "full_keep_last": 8 }

Secrets: none. Sources are transcript/memory/paths only; never raw keys, never logged verbatim.
