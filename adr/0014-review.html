call_agent_process — external harnesses

Keep Marble’s multi-session UX; delegate deep coding work to headless Claude Code / Grok Build (and future CLIs) via a generic tool + driver adapters.

Date2026-07-18
Sourceadr/0014-call-agent-process.md
tool call_agent_process format grok | claude mode headless -p cwd workspace jail

1. Why

Marble

  • Sessions, memory, soul, MCP, progress UI
  • Operator cockpit

External harnesses

  • Deep multi-file agent loops
  • Specialized models/tools/permissions
  • Headless: claude -p, grok -p … --output-format json
Not arbitrary shell — dedicated tool + allowlisted drivers, argv built in-process (no shell injection).

2. Tool sketch

call_agent_process({
  format: "grok" | "claude",   // driver
  prompt: "…",                 // required
  cwd?: "rel/path",            // under workspace
  output_format?: "plain"|"json",
  timeout_sec?: number,
  extra_args?: string[]        // driver-allowlisted
})

→ {
  format, ok, exit_code, duration_ms, cwd,
  summary,   // primary text for Marble model
  raw?,      // parsed vendor JSON if any
  stderr_tail?
}

3. Drivers (illustrative argv)

# Grok Build (local --help)
grok -p "$PROMPT" --output-format json --cwd "$CWD" …

# Claude Code (ecosystem; verify at implement)
claude -p "$PROMPT" …

Config: $MEMORY/agent_process.json — enable drivers, command path, default_args, timeouts.
